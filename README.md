# Tic-Tac-Toe

A simple browser-based Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Features

- Play Tic-Tac-Toe in the browser
- Enter custom names for Player 1 and Player 2
- Turn-based gameplay with win and draw detection
- Restart button to start a new game

## Project Files

- index.html - Main page structure
- style.css - Styling for the game board and layout
- script.js - Game logic and DOM interactions

## How to Run

1. Open the project folder in your browser.
2. Open index.html directly, or serve the folder with a simple local server.

Example with Python:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000 in your browser.

## How to Play

- Enter a name for each player.
- Click a square on the board to place your marker.
- The first player to complete a row, column, or diagonal wins.
- If all squares are filled without a winner, the game ends in a draw.
